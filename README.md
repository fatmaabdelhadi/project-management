# Focus Hive – Project Management Platform (Frontend)

Frontend for **Focus Hive**, a MERN-based project management platform designed to help teams organize tasks, track progress, and manage project dependencies.

## Tech Stack
React.js • JavaScript • React Bootstrap

## Backend
The backend API for this project is available here:  
https://github.com/fatmaabdelhadi/project-management-backend

## Overview
Focus Hive enables teams to:
- Manage projects and tasks
- Visualize task dependencies
- Track progress and team workload
- Use role-based access for collaboration

This repository contains the **React frontend** for the platform.
